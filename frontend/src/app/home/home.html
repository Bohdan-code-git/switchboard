How it works

  1. You pick a provider The API creates a one-time state, plus a PKCE verifier for Google and GitHub, and sends you to the provider.
  2. The provider asks you You approve read-only access to your profile. Nothing else: no mailbox, repositories, servers or messages.
  3. The API finishes the exchange It checks the state, swaps the code for tokens, keeps them encrypted on the server and sends only the profile to this page.
